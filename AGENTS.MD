## Project Overview
EverSince we met, a romantic web experience made for couples recurrences like anniversaries. It is designed to be customizable and extendible, with non-tech-savy users in mind.

## Working rules
- Work on one feature at a time.
- Keep changes within the selected feature scope unless a blocker forces a narrow supporting fix.
- Do not silently change verification rules during implementation.
- Prefer durable repo artifacts over chat summaries.
